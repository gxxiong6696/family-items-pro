# 家庭物品管理系统 · 专业版

离线本地 PWA，管理家庭物品：药品/食品效期、家电保修、证件归档。**专业版特性：物品照片以原图质量存入 IndexedDB，数量无上限（受浏览器配额，通常数 GB），永不压缩降质。**

> 本仓库只含网页源码与公钥，**不含任何私钥**。注册码生成器（含私钥）由作者本地保管。

## 与普通版的区别

| | 普通版  | 专业版（本仓库） |
|---|---|---|
| 照片存储 | 压缩后存 localStorage（约 5MB 上限） | **原图存 IndexedDB（数 GB 配额）** |
| 适用场景 | 轻量记录 | 证件/药品高清照片、长期大量 |
| App ID | com.family.items.pwa | com.family.items.pro（可共存） |

两版数据可通过「加密备份」互通：专业版导出「普通版兼容包」→ 普通版导入。

## 功能

- 物品增删改查、分类管理（药品/食品/家电/证件…）
- 搜索：关键词 + 拼音首字母 + 分类名
- 按存放位置查看（房间 → 收纳位两级树）
- 拍照存档：原图直存 IndexedDB，证件类高清
- 提醒中心：药品效期 / 食品保质期 / 家电保修（以记录的"有效期至"为准）
- 位置页双模式（查询/编辑）+ 一键折叠
- 加密备份导出/导入（用户名+密码），支持合并导入（多设备同步）
- 启动密码锁（可选）
- 离线可用（Service Worker 缓存）


## 备份与安全

- 导出加密备份（用户名+密码），支持「完整备份（原图）」与「普通版兼容包（压缩）」两种
- 导入支持「合并导入」（两设备同步推荐）与「覆盖导入」
- 数据仅存本机，不上传任何服务器
